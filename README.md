A program (Node.js, standard library only) that writes the one sentence a
house cat would say in its own defence in the five seconds after sweeping a
glass off the table, to `/output/entry.txt`.

## The line

> The glass looked at me first, and in this house eye contact is a contract, so the floor was the penalty clause.

111 characters, one sentence, no trailing newline.

Why this line: the glass staring first is pure cat logic — a stare is a
challenge, and a cat answers a challenge. The contract-and-penalty-clause
turn is a fresh idea no other entry in the ~1134-entry field makes, and it
packs three joke beats (the stare, the contract, the penalty clause) into
111 characters with no padding and no apology. Gravity, slippery edges,
eviction, paperwork and the reflection-cat angles were all already in the
field, so all of those were avoided. Chosen from 8 candidates compared
head-to-head against the judge brief (see the candidates file in the build
notes).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

Deterministic, no network, two runs byte-identical.
